## Wine Shop Web Application

This is a web application for ordering wine products online, designed to provide users with a smooth and intuitive shopping experience. The application allows users to browse a selection of wine products, view detailed product information, and place orders easily through a modern and responsive interface.

The application is built using **React**, with **Redux** used for global state management, including handling application data and product state. For UI is used **Material UI (MUI)** , to create consistent, responsive, and visually appealing components.
